◆ calc_rich_ex()

subroutine, public rich_ops::calc_rich_ex ( complex(dp), dimension(:), intent(in) sol_val)

Calculates the coefficients of the Eigenvalues in the Richardson extrapolation.

This is done using the recursive formula:

\[ s(l,i,:) = s(l,i-1,:) + \frac{1}{2^{2 \ p \ i} - 1} (s(l,i-1,:) - s(l-1,i-1,:)), \]

where \(s\) = sol_val_rich, \(i\) = ir, \(l\) = lvl and \(p\) = norm_disc_prec_sol, the order of the numerical discretization. as described in [3], algorithm 3.2, p. 306.

Parameters
[in]sol_valEV for this Richardson level

◆ find_max_rich_lvl()

integer function, public rich_ops::find_max_rich_lvl ( integer, intent(out) max_lvl_rich_file)

Probe to find out which Richardson levels are available.

The solution groups sol_R_1, sol_R_2, ... are probed from level 1 upward; the highest level is the last one found before the first missing one, and 0 if there is no solution at all.

Returns
ierr
Parameters
