◆ abort_mpi()

integer function, public mpi_ops::abort_mpi ( integer, intent(in) status)

Abort MPI suddenly.

MPI_Abort ends all the processes of the run. It hands status to the launcher (mpirun, srun, ...), which returns it to the shell as its exit status. A process that was started without a launcher returns status itself.

See also
get_exit_status() for the value to pass.

◆ stop_usage()

subroutine, public mpi_ops::stop_usage ( integer, intent(in) status)

Stops all processes after the usage or help message.

Only rank 0 reads the command line, in parse_args(). The main programs broadcast the exit status that it returns, and every process then calls this routine. Every process has to call it, because stop_MPI() makes collective calls: a process that stopped alone would wait in them for the others, which would wait in their next broadcast for it, and the run would never end.

The program ends with exit status status and prints nothing more, as the usage or help message has already been printed.

[in]statusexit status

◆ sudden_stop()

subroutine, public mpi_ops::sudden_stop ( integer, intent(in) ierr)

Suddenly stops the computations, aborting MPI, etc.

The error code ierr is printed and MPI is aborted with abort_MPI(). The program then ends with the exit status of get_exit_status(), which is not zero, so that a shell script, a batch system or a test sees that the run failed.

Before the abort, the buffered output on the screen and in the output file is written out: MPI_Abort ends the process without doing this, and the error message would be lost when the output goes to a file or to a pipe.

The stop after the usage or help message is not an error and goes through stop_usage().

[in]ierrerror to output
