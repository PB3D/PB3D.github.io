Calculate the trigonometric cosine and sine basis.

The basis holds, at given 3-D arrays for the (VMEC) E(quilibrium) angles \(\theta_\text{E}\) and \(\zeta_\text{E}\),

  • \(\cos(m \theta)\) and \(\sin(m \theta)\) for \(m = 0 \ldots \text{mpol_tf}-1\) at index \(m+1\),
  • \(\cos(n N_\text{fp} \zeta)\) and \(\sin(n N_\text{fp} \zeta)\) for \(n = -\text{ntor_tf} \ldots \text{ntor_tf}\) at index \(\text{mpol_tf} + \text{ntor_tf} + 1 + n\),

so that the dimensions of the output array are

(1:n_ang_1,1:n_ang_2,1:n_r,1:mpol_tf+2*ntor_tf+1,1:2)

where the last index selects cosine (1) or sine (2) and n_r is the total number of normal points; the points come first so that one basis function is contiguous over the grid. fourier2real() forms \(\cos(m \theta - n \zeta)\) and \(\sin(m \theta - n \zeta)\) from the basis per mode, so the same basis serves the main VMEC mode set and the Nyquist set of the Jacobian, \(|B|\) and \(B_i\): mpol_tf and ntor_tf cover both (see VMEC_ops.read_VMEC()).
