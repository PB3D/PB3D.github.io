1!------------------------------------------------------------------------------!
2!> Operations and variables pertaining to the vacuum response.
3!!
4!! The vacuum response is calculated using the Boundary Element Method. There
5!! are two possibilities, indicated by the variable \c style in \c vac_vars.
6!! -# 3-D field aligned:
7!! - Makes use of the collocation method for the grid points along the
8!! magnetic field lines.
9!! - The surface integrals are taken in the parallel coordinate and the
10!! field-line label, with the trapezoidal rule along every field line,
11!! refined near the influence point, and a sum with equal weights
12!! across the field lines, which together cover the surface once (see
13!! calc_gh_1()).
14!! - At least 2 field lines are required, with alpha_style=2.
15!! -# axisymmetric:
16!! - Makes use of an analytical expression for the toroidal integration of
17!! the Green's functions, as shown in \cite Cohl1999.
18!! - The integration in the poloidal angle is done using the collocation
19!! method.
20!!
21!! The final matrix equation is solved through Strumpack \cite Meiser2016,
22!! or through ScaLAPACK when PB3D was built without Strumpack.
23!!
24!! \see See \cite Weyens3D.
25!!
26!! \todo Publish vacuum benchmarks and refer to them here.
27!! \todo Investigate Strumpack rather than inefficient scalapack
28!------------------------------------------------------------------------------!

66 !> Stores calculation of the vacuum response by storing the necessary
67 !! variables.
68 !!
69 !! This is done by the last process, which is the one that contains the
70 !! variables at the plasma edge, and then this is broadcasted to the other
71 !! processes.
72 !!
73 !! The workings of this routine are summarized in the following diagram for
74 !! VMEC:
75 !! @dot
76 !! digraph G {
77 !! eq_job -> restart [label=<yes>]
78 !! eq_job -> store [label=<no>]
79 !! restart -> jump [label=<yes>]
80 !! restart -> copy [label=<no>]
81 !! jump -> reconstructcur [label=<yes>]
82 !! jump -> restartone [label=<no>]
83 !! reconstructcur -> return
84 !! restartone -> reconstruct [label=<no>]
85 !! copy -> store
86 !! reconstruct -> store
87 !! restartone -> store [label=<yes>]
88 !! store -> return
89 !!
90 !! eq_job [shape=diamond,label=<eq_job = 1>]
91 !! store [label=<store new vec, res>]
92 !! restart [shape=diamond,label=<restart>]
93 !! jump [shape=diamond,label=<jump>]
94 !! copy [label=<copy previous level>]
95 !! reconstructcur [label=<reconstruct current level>]
96 !! return [label=<return>]
97 !! restartone [shape=diamond,label=<restart = 1>]
98 !! reconstruct [label=<reconstruct previous level>]
99 !! }
100 !! @enddot
101 !!
102 !! Before storing the new variables, the procedure checks the following
103 !! things:
104 !! - For the first equilibrium job, this routine copies the results from
105 !! the previous Richardson level into the appropriate subranges of the new
106 !! vacuum variables if no restart of Richardson levels was done.
107 !! - If a restart was done and the level is greater than one, there is a
108 !! reconstruction of the previous level's variables. But this will happen
109 !! in calc_vac_res(), not in this procedure.
110 !!
111 !! If there is a jump straight to the solution, however, the procedure
112 !! returns after reconstructing the current level's variables.
113 !!
114 !! If the previous \c G and \c H variables are empty, they are regenerated
115 !! later, in calc_gh(). This indicates that a reconstruction happened,
116 !! either because a Richardson restart was performed, or because a new
117 !! Richardson level was started after a previous level in which it was
118 !! jumped straight to the solution.

121 !! level, and the vacuum has to be calculated only once then. If there is a
122 !! jump to solution or if there is Richardson restart, it only needs to be

509 !> Calculate the matrices \c G and \c H.
510 !!
511 !! This is done by iterating over the subintervals, calculating the
512 !! contributions to the potential values on the left and right boundary of
513 !! the interval, and adding these to the appropriate values in G and H.
514 !!
515 !! As each process in the blacs grid only has access to its own values, an
516 !! extra interval is is calculated to the left and right of the internal
517 !! process grid edges.
518 !!
519 !! Optionally, this procedure can be used to calculate the coefficients G
520 !! and H with respect to other points, outside of the boundary. This is
521 !! useful when the potential is to be calculated at external points.
522 !!
523 !! For external points no diagonal is set, and the points near the boundary
524 !! are treated as follows:
525 !! - field-line style (calc_gh_1()): the near-field rule along the field
526 !! lines is used for an external point that lies closer to its nearest
527 !! boundary point than that boundary point lies to its neighbour on the
528 !! same field line. A point that coincides with a boundary point gets
529 !! the analytical half-cell integral of G, with the metric factors of
530 !! the left endpoint of the interval, which is the coinciding point or
531 !! its neighbour on the field line.
532 !! - axisymmetric style (calc_gh_2()): a point that coincides with a
533 !! boundary point gets the row that returns the boundary value, with
534 !! \f$4\pi\f$ in the column of that point and zero elsewhere. Other
535 !! points near the boundary get no special treatment.
536 !!
537 !! Within a few grid spacings of the boundary the quadrature does not
538 !! resolve the kernels (eval_pot_ext()).
539 !!
540 !! \note Multiple field lines are stored sequentially, which implies that
541 !! the integral between the last point on a field line and the first point
542 !! on the next field lines needs to be left out.
543 !!
544 !! \note For style 1 the kernel is integrated along the field line within
545 !! four interval lengths of the influence point (vac_utilities.calc_gh_int_1),
546 !! because neighbouring field lines can lie much closer together than
547 !! the points along them. The rule along and across the field lines is
548 !! described in calc_gh_1().
549 !!
550 !! \todo For 3-D vacuums, step sizes are constant. Subsequent Richardson
551 !! levels should therefore make use of the fact that the contribution to the
552 !! points inherited from the previous levels can be just scaled by 1/2 and
553 !! do not need to be recalculated. Currently, the copy is done correctly in
554 !! interlaced_vac_copy(), but they are afterwards overwritten.
555 !!
556 !! \return ierr
557 integer function calc_gh(vac,n_r_in,lims_r_in,x_vec_in,G_in,H_in) &
558 &result(ierr)

726 !> \public Calculates matrices \c G and \c H in 3-D configuration.
727 !!
728 !! The boundary points lie on \f$n_\alpha\f$ field lines with the labels
729 !! \f$\alpha_k = \alpha_\text{min} + (k-1)\Delta\alpha\f$,
730 !! \f$k = 1,\ldots,n_\alpha\f$. Every field line has \f$n_p\f$ points
731 !! \f$p_l = p_\text{min} + (l-1)\Delta p\f$, \f$l = 1,\ldots,n_p\f$, in
732 !! the parallel coordinate \f$p\f$. The steps are
733 !! \f$\Delta\alpha = (\alpha_\text{max}-\alpha_\text{min})/n_\alpha\f$ and
734 !! \f$\Delta p = (p_\text{max}-p_\text{min})/(n_p-1)\f$
735 !! (vac_utilities.vac_steps()): the grid in \f$\alpha\f$ leaves out
736 !! \f$\alpha_\text{max}\f$, which is the field line at
737 !! \f$\alpha_\text{min}\f$ again, while every field line includes both of
738 !! its end points. The points are stored line by line: point \f$l\f$ of
739 !! field line \f$k\f$ is column \f$j = (k-1)n_p + l\f$ of G and H.
740 !!
741 !! A row of G and H belongs to an influence point \f$\mathbf{r}_i\f$, the
742 !! point at which the potential is evaluated. A column belongs to a
743 !! boundary point \f$\mathbf{r}_j\f$, over which the surface integral
744 !! runs.
745 !!
746 !! The surface integrals are taken in the coordinates \f$(p,\alpha)\f$.
747 !! With alpha_style 2 the parallel range is one turn,
748 !! \f$p_\text{max}-p_\text{min} = 2\pi\f$, and the field lines have to
749 !! cover one period of the label,
750 !! \f$\alpha_\text{max}-\alpha_\text{min} = 2\pi\f$ (the default). The
751 !! rectangle in \f$(p,\alpha)\f$ then covers the surface once. The stored
752 !! normal \f$\mathbf{N} = -\mathcal{J}\nabla\psi\f$ (\c vac\%norm) has the
753 !! length of the surface element per unit \f$p\f$ and per unit
754 !! \f$\alpha\f$,
755 !! \f$|\mathbf{N}| = |\partial_\alpha\mathbf{r}\times\partial_p\mathbf{r}|\f$,
756 !! so the weights below contain no other Jacobian.
757 !!
758 !! Far from the influence point, the rule is
759 !! \f[ \iint f \, \text{d}p \, \text{d}\alpha \approx
760 !! \sum_{k=1}^{n_\alpha} \Delta\alpha \sum_{l=1}^{n_p} c_l \, \Delta p \,
761 !! f(p_l,\alpha_k), \qquad c_1 = c_{n_p} = \tfrac{1}{2}, \quad
762 !! c_l = 1 \text{ otherwise}, \f]
763 !! where \f$f\f$ is the integrand of the G term or of the H term of row
764 !! \f$i\f$.
765 !! - Along each field line this is the trapezoidal rule. The loop over
766 !! the intervals \f$[p_l,p_{l+1}]\f$ multiplies the kernel at both end
767 !! points of every interval by \f$\Delta p\,\Delta\alpha/2\f$ and adds
768 !! it to their columns. A point inside a field line therefore collects
769 !! the weight \f$\Delta p\,\Delta\alpha\f$, and the first and the last
770 !! point of a field line collect \f$\Delta p\,\Delta\alpha/2\f$. The
771 !! last point of one field line and the first point of the next are
772 !! neighbours in the storage only, and the loop skips that pair.
773 !! - Across the field lines it is a sum with the equal weight
774 !! \f$\Delta\alpha\f$, which is the trapezoidal rule for a function
775 !! that is periodic in \f$\alpha\f$. The kernel is evaluated on the
776 !! field lines only; nothing is interpolated between them.
777 !!
778 !! Near the influence point, vac_utilities.calc_gh_int_1() changes the
779 !! rule along the field line and leaves the sum across the field lines as
780 !! it is. Within four interval lengths of the influence point it
781 !! integrates the kernel over each half-interval with Gauss-Legendre
782 !! points on the cubic through four points of the same field line; for
783 !! the first and the last interval of a field line these four points lie
784 !! on one side of the interval. For an influence point off the boundary
785 !! this is done only if the point lies closer to its nearest boundary
786 !! point than that boundary point lies to its neighbour on the same field
787 !! line. At the singular point it uses the analytical integral
788 !! over the half-cell, which reaches \f$\Delta\alpha/2\f$ to either side
789 !! of the field line. That integral and the cell integral of the direct
790 !! diagonal of H (vac_utilities.calc_diag_direct(), only with
791 !! \c vac_diag_style 2) are the only places where the kernel is integrated
792 !! across the field lines.
793 !!
794 !! \see calc_gh.
795 integer function calc_gh_1(vac,n_r_in,lims_r_in,x_vec_in,G_in,H_in,ext_in) &
796 &result(ierr)
797
798 use vac_utilities, only: calc_gh_int_1, vac_steps
799 use grid_vars, only: n_alpha
800 use num_vars, only: tol_zero
801 use vac_vars, only: loc_idx
802
803 character(*), parameter :: rout_name = 'calc_GH_1'
804
805 ! input / output
806 type(vac_type), intent(inout) :: vac !< vacuum variables
807 integer, intent(in) :: n_r_in !< total number of rows of external poins of influence
808 integer, intent(in) :: lims_r_in(:,:) !< row limits of external points of influence
809 real(dp), intent(in) :: x_vec_in(:,:) !< position of influence
810 real(dp), intent(in), pointer :: g_in(:,:) !< G at position of influence
811 real(dp), intent(in), pointer :: h_in(:,:) !< H at position of influence

840 ! the singular self-integrals and the integration rule weights of
841 ! calc_vac_res) degenerate; covering the surface with one long

854 ! set up local tolerance
855 tol_loc = tol_zero*10 ! tolerance for singular interval
856
857 ! iterate over all subrows: position of singular point
858 subrows: do i_rd = 1,size(lims_r_in,2)
859 ! iterate over all rows of this subrow
860 row: do rd = lims_r_in(1,i_rd),lims_r_in(2,i_rd)
861 ! set local row index
862 rdl = loc_idx(lims_r_in,i_rd,rd)
863
864 ! the near-field rule along the lines: always for a boundary
865 ! point; for an external point only if it lies within an
866 ! interval length of the nearest boundary point (see
867 ! calc_GH_int_1; every process holds all boundary points)
868 near_row = .true.
869 if (ext_in) then
870 j_min = minloc(sum((vac%x_vec-spread(x_vec_in(rd,:),1,&
871 &vac%n_bnd))**2,2),1)
872 j_nb = j_min+1 ! neighbour on the same line
873 if (mod(j_min,vac%n_ang(1)).eq.0) j_nb = j_min-1
874 near_row = sum((vac%x_vec(j_min,:)-x_vec_in(rd,:))**2).lt.&
875 &sum((vac%x_vec(j_nb,:)-vac%x_vec(j_min,:))**2)
876 end if
877
878 ! iterate over all subcolumns: subintegrals
879 subcols: do i_cd = 1,size(vac%lims_c,2)
880 ! set up local limits, including possible overlap
881 lims_c_loc(1) = max(1,vac%lims_c(1,i_cd)-1)
882 lims_c_loc(2) = min(vac%n_bnd,vac%lims_c(2,i_cd)+1)
883
884 ! iterate over all pairs of columns of this subcolumn
885 ! (upper limit is one lower as lims_c_loc
886 col: do cd = lims_c_loc(1),lims_c_loc(2)-1
887 ! cd is the last point of a field line and cd+1 the
888 ! first point of the next one (points are stored
889 ! line by line): these two points are not the ends
890 ! of an interval on the surface, so there is nothing
891 ! to integrate here. Both points still enter every
892 ! row as sources, with the half weight of the end
893 ! of their own line.
894 if (mod(cd,vac%n_ang(1)).eq.0) cycle col
895
896 ! set local column index
897 cdl = loc_idx(vac%lims_c,i_cd,cd)
898
899 ! four-point stencil along the field line, one-sided
900 ! at its ends
901 st = (cd-1)/vac%n_ang(1)*vac%n_ang(1) ! last point of the previous field line
902 st = max(st+1,min(cd-1,st+vac%n_ang(1)-3))
903
904 ! metric factors at the influence point, used only
905 ! for the singular half-cell; an external point has
906 ! none (its row index does not number a boundary
907 ! point), and should it coincide with a boundary
908 ! point, the factors of the left endpoint cd of the
909 ! interval are used, which is that point or its
910 ! neighbour on the field line
911 if (ext_in) then
912 h_fac_in = vac%h_fac(cd,:)
913 else
914 h_fac_in = vac%h_fac(rd,:)
915 end if
916
917 ! calculate contributions to H and G
918 call calc_gh_int_1(g_loc,h_loc,&
919 &vac%x_vec(st:st+3,:),x_vec_in(rd,:),&
920 &vac%norm(st:st+3,:),h_fac_in,&
921 &[dpar_x,dalpha],tol_loc**2,cd-st+1,&
922 &use_near=near_row)
923
924 ! loop over left and right side of interval
925 ! (the contributions are weighted with the half-cell
926 ! surface element dpar dalpha / 2, so that G and H are
927 ! true discretized surface operators, consistently
928 ! with the absolute -4 pi row-sum identity that sets
929 ! the H diagonal below, and with the axisymmetric
930 ! style, which carries its weights internally as well)
931 do kd = 0,1
932 if (cd+kd.ge.vac%lims_c(1,i_cd) .and. & ! lower local bound
933 &cd+kd.le.vac%lims_c(2,i_cd)) then ! upper local bound
934 g_in(rdl,cdl+kd) = g_in(rdl,cdl+kd) + &
935 &g_loc(1+kd)*dpar_x*dalpha/2._dp
936 h_in(rdl,cdl+kd) = h_in(rdl,cdl+kd) + &
937 &h_loc(1+kd)*dpar_x*dalpha/2._dp
938 end if
939 end do
940 end do col
941 end do subcols
942 end do row
943 end do subrows
944 end function calc_gh_1

1064 ! If the boundary point j_sing nearest to an external point is
1065 ! closer than tol_loc, the code treats the external point as
1066 ! j_sing. Its row then has G = 0 in every column, and H = 4 pi
1067 ! in column j_sing and 0 in every other column, so that
1068 ! eval_pot_ext returns the boundary value phi(j_sing). The
1069 ! search for j_sing runs over all boundary points, which every
1070 ! process holds, so all processes make the same choice for the
1071 ! row. Every other external point is farther than tol_loc from
1072 ! every boundary point, so calc_GH_int_2 always takes its

1556 !! First \c G and \c H are completed if this is not the first Richardson

1558 !!

1564 !! \f$\overline{\text{P}}\overline{\text{E}}^\dagger\f$.
1565 !!
1566 !! The non-square matrix \f$\overline{\text{E}}\f$ contains the exponents
1567 !! for different mode numbers and different poloidal grid points, whereas
1568 !! \f$\overline{\text{P}}\f$ are diagonal matrices that contain the factors

1971 ! The projection of Phi on the data with the integration rule (the trapezoidal weights along the lines; the average over the lines for the field-line style), gathered on the last process.
1972 !> \private
1973 subroutine project_response()
1974 ! Convert EP into IEP where I contains the integration rule:
1975 ! (θ_{i+1}-θ_{i-1})/2 for i = 2..n-1
1976 ! I_i = (θ_2-θ_1}/2 for i = 1
1977 ! (θ_{n}-θ_{n-1}}/2 for i = n
1978 ! with n = vac%n_bnd.
1979 ! For vacua of type 1, the step size is constant. Also, there is an
1980 ! additional step size in the alpha direction.
1981 subrows3: do i_rd = 1,size(vac%lims_r,2)
1982 row3: do rd = vac%lims_r(1,i_rd),vac%lims_r(2,i_rd)
1983 ! set local row index
1984 rdl = loc_idx(vac%lims_r,i_rd,rd)
1985
1986 subcols3: do i_cd = 1,size(lims_c_loc,2)
1987 ! set local column limits
1988 lims_cl = [loc_idx(lims_c_loc,i_cd,lims_c_loc(1,i_cd)), &
1989 &loc_idx(lims_c_loc,i_cd,lims_c_loc(2,i_cd))]
1990
1991 select case (vac%style)
1992 case (1) ! field-line 3-D
1993 ! the projection integrates over the field
1994 ! lines as well: dalpha divided by the alpha
1995 ! span gives the average over the lines, the
1996 ! per-toroidal-mode normalization of the
1997 ! axisymmetric style
1998 i_loc = dpar_x/n_alpha
1999 if (mod(rd-1,vac%n_ang(1))+1.eq.1 .or. & ! first point on field line
2000 &mod(rd-1,vac%n_ang(1))+1.eq.vac%n_ang(1)) &! last point on field line
2001 &i_loc = i_loc*0.5_dp
2002 case (2) ! axisymmetric
2003 i_loc = 0.5_dp*&
2004 &(vac%ang(min(rd+1,vac%n_bnd),1)-&
2005 &vac%ang(max(rd-1,1),1))
2006 end select
2007
2008 ep(rdl,lims_cl(1):lims_cl(2)) = &
2009 &ep(rdl,lims_cl(1):lims_cl(2)) * i_loc
2010 end do subcols3
2011 end do row3
2012 end do subrows3
2013
2014 ! calculate (EP)^T Phi
2015 ! Note that this means that the second half of the rows in EP^T are
2016 ! still missing a minus sign if they are to represent EP^†. This
2017 ! will be taken into account when res2_loc is converted to vac%res.
2018 call pdgemm('T','N',2*n_mod_x,2*n_mod_x,vac%n_bnd,1._dp,ep,1,1,&
2019 &desc_phiep,phi,1,1,desc_phiep,0._dp,res2,1,1,desc_res2)
2020
2021 ! get serial version on last process
2022 ierr = mat_dis2loc(vac%ctxt_HG,res2,lims_r_loc,lims_c_loc,res2_loc,&
2023 &proc=n_procs-1)
2024 chckerr('')
2025 end subroutine project_response

2027 ! The response as a complex matrix, divided by the permeability, multiplied by 2 pi (the toroidal integral) and made Hermitian.
2028 !> \private
2029 subroutine finish_response()
2030 ! convert to complex numbers and save in vac%res
2031 vac%res = res2_loc(1:n_mod_x,1:n_mod_x)-&
2032 &(-res2_loc(n_mod_x+1:2*n_mod_x,n_mod_x+1:2*n_mod_x)) ! minus sign for lower rows
2033 vac%res = vac%res + iu * &
2034 &(res2_loc(1:n_mod_x,n_mod_x+1:2*n_mod_x)-&
2035 &res2_loc(n_mod_x+1:2*n_mod_x,1:n_mod_x)) ! minus sign for lower rows
2036 vac%res = vac%res/vac_perm
2037 ! Bring res to the surface-energy Hessian as it enters the
2038 ! potential-energy matrix A, so that the free boundary
2039 ! condition adds X_e^H res X_e (set_BC_2, set_BC_4) and POST
2040 ! adds the same term to E_pot. The matrix A corresponds to 2 dW
2041 ! with the toroidal integral included (alpha_fac = 2 pi for a
2042 ! single field line). With the normal data along the stored
2043 ! normal -J nabla psi, out of the vacuum, the vacuum energy is
2044 ! dW_vac = 1/(2 mu_0) int dphi^* phi dS >= 0, so res up to here
2045 ! is the positive Neumann-to-Dirichlet map per unit toroidal
2046 ! angle and 2 dW_vac = 2 pi X_e^H res X_e. In the
2047 ! large-aspect-ratio cylinder the vacuum energy of an edge
2048 ! displacement equals the field-line bending energy of a plasma
2049 ! layer of thickness a/|m| at the edge, 4 pi^2 (nq-m)^2 |X_e|^2
2050 ! / (mu_0 R_0 |m|) in A (full-stack test vac_response_cylinder).
2051 ! Checked against MISHKA-1 on the circular external kink.
2052 vac%res = 2._dp*pi*vac%res
2053
2054 ! The exact operator is Hermitian; the discretization leaves
2055 ! an asymmetry of about 1E-5 that makes SLEPC reject tightly
2056 ! converged eigenvalues as complex. Keep the Hermitian part.
2057 vac%res = 0.5_dp*(vac%res+conjg(transpose(vac%res)))
2058 end subroutine finish_response

2060 end function calc_vac_res

2626 !> \public Potential at points off the boundary, from its values and its
2627 !! normal data on the boundary.
2628 !!
2629 !! The kernels are taken along the stored normal \f$-\mathcal{J}\nabla\psi\f$,
2630 !! which points out of the vacuum. Green's second identity then gives, at a
2631 !! point \f$\vec{x}\f$ off the boundary,
2632 !! \f[ \sum_j \left( H(\vec{x},\vec{x}_j)\phi_j -
2633 !! G(\vec{x},\vec{x}_j)\,\text{d}\phi_j \right) = \left\{
2634 !! \begin{array}{ll}
2635 !! 4\pi\phi(\vec{x}) & \text{in the vacuum,} \\
2636 !! 0 & \text{in the plasma}
2637 !! \end{array} \right. \f]
2638 !! for a potential \f$\phi\f$ that is harmonic in the vacuum and decays at
2639 !! infinity, and \f$0\f$ in the vacuum and \f$-4\pi\phi(\vec{x})\f$ in the
2640 !! plasma for a potential harmonic inside the boundary (the constant for the
2641 !! field-line style, \f$R^{|n|}\f$ for the axisymmetric one). On the boundary
2642 !! the same sum, with the diagonal that calc_GH() adds there, is the identity
2643 !! \f$\overline{\text{H}}\phi - \overline{\text{G}}\,\text{d}\phi = c\phi\f$
2644 !! of solve_Phi_BEM(), \f$c = 0\f$ and \f$-4\pi\f$ for the two kinds.
2645 !!
2646 !! This routine returns the sum divided by \f$4\pi\f$ for every column of
2647 !! \c Phi_s and \c D_s. The rows of G and H are assembled by calc_GH() for
2648 !! the external points (no diagonal; the trapezoidal rule with the near-field
2649 !! rule along the field lines for the field-line style, the toroidal-function
2650 !! kernels for the axisymmetric style), in chunks that bound the memory.
2651 !! Within a few grid spacings of the boundary the quadrature does not
2652 !! resolve the kernels.
2653 !!
2654 !! Every process of the BLACS grid of the vacuum has to call it.
2655 !!
2656 !! \return ierr
2657 integer function eval_pot_ext(vac,x_ext,Phi_s,D_s,desc_s,pot) result(ierr)
2658 use vac_vars, only: in_context, set_loc_lims
2659 use vac_utilities, only: mat_dis2loc
2660
2661 character(*), parameter :: rout_name = 'eval_pot_ext'
2662
2663 ! input / output
2664 type(vac_type), intent(inout) :: vac !< vacuum variables
2665 real(dp), intent(in) :: x_ext(:,:) !< points: (R,Z) for the axisymmetric style, (x,y,z) for the field-line style; the same on every process
2666 real(dp), intent(in) :: phi_s(:,:) !< local part of the boundary potential, n_bnd by n_col
2667 real(dp), intent(in) :: d_s(:,:) !< local part of its normal data along the stored normal
2668 integer, intent(in) :: desc_s(blacsctxtsize) !< descriptor of \c Phi_s and \c D_s
2669 real(dp), intent(inout) :: pot(:,:) !< potential at the points, n_ext by n_col, on every process of the BLACS grid
2670
2671 ! local variables
2672 integer, parameter :: max_entries = 20000000 ! largest block of external rows of G or H
2673 integer :: n_ext ! number of points
2674 integer :: n_col ! number of columns
2675 integer :: n_ch ! points per chunk
2676 integer :: i_1, i_2, n_r ! first and last point of a chunk and their number
2677 integer :: n_row_loc, n_col_loc ! local numbers of rows and columns
2678 integer :: desc_gh(blacsctxtsize) ! descriptor of the external rows of G and H
2679 integer :: desc_p(blacsctxtsize) ! descriptor of the potential of a chunk
2680 integer, allocatable :: lims_r_loc(:,:) ! local row limits of a chunk
2681 integer, allocatable :: lims_c_loc(:,:) ! local column limits
2682 real(dp), allocatable :: g_loc(:,:), h_loc(:,:) ! external rows of G and H
2683 real(dp), allocatable :: p_loc(:,:) ! local part of the potential of a chunk
2684 real(dp), allocatable :: p_ser(:,:) ! potential of a chunk, gathered
2685
2686 ! initialize ierr
2687 ierr = 0
2688
2689 n_ext = size(x_ext,1)
2690 n_col = size(pot,2)
2691 pot = 0._dp
2692 n_ch = max(1,min(n_ext,max_entries/max(1,vac%n_bnd)))
2693
2694 ! local columns of the result
2695 n_col_loc = 0
2696 if (in_context(vac%ctxt_HG)) n_col_loc = &
2697 &numroc(n_col,vac%bs,vac%ind_p(2),0,vac%n_p(2))

2699
2700 ! chunks of points
2701 i_1 = 1
2702 do while (i_1.le.n_ext)
2703 i_2 = min(n_ext,i_1+n_ch-1)
2704 n_r = i_2-i_1+1
2705 n_row_loc = 0
2706 if (in_context(vac%ctxt_HG)) n_row_loc = &
2707 &numroc(n_r,vac%bs,vac%ind_p(1),0,vac%n_p(1))
2708 call set_loc_lims(n_row_loc,vac%bs,vac%ind_p(1),vac%n_p(1),&
2709 &lims_r_loc)
2710
2711 ! external rows of G and H
2712 allocate(g_loc(max(1,n_row_loc),max(1,vac%n_loc(2))))
2713 allocate(h_loc(max(1,n_row_loc),max(1,vac%n_loc(2))))
2714 g_loc = 0._dp
2715 h_loc = 0._dp
2716 ierr = calc_gh(vac,n_r_in=n_r,lims_r_in=lims_r_loc,&
2717 &x_vec_in=x_ext(i_1:i_2,:),g_in=g_loc,h_in=h_loc)
2718 chckerr('')
2719
2720 ! (H Phi - G D) / 4 pi, gathered
2721 if (in_context(vac%ctxt_HG)) then
2722 call descinit(desc_gh,n_r,vac%n_bnd,vac%bs,vac%bs,0,0,&

2726 &vac%ctxt_HG,max(1,n_row_loc),ierr)

2729 p_loc = 0._dp
2730 call pdgemm('N','N',n_r,n_col,vac%n_bnd,1._dp/(4*pi),h_loc,&
2731 &1,1,desc_gh,phi_s,1,1,desc_s,0._dp,p_loc,1,1,desc_p)
2732 call pdgemm('N','N',n_r,n_col,vac%n_bnd,-1._dp/(4*pi),g_loc,&
2733 &1,1,desc_gh,d_s,1,1,desc_s,1._dp,p_loc,1,1,desc_p)
2734 allocate(p_ser(n_r,n_col))
2735 ierr = mat_dis2loc(vac%ctxt_HG,p_loc(1:n_row_loc,1:n_col_loc),&
2736 &lims_r_loc,lims_c_loc,p_ser)
2737 chckerr('')
2738 pot(i_1:i_2,:) = p_ser
2739 deallocate(p_loc,p_ser)
2740 end if
2741
2742 deallocate(g_loc,h_loc,lims_r_loc)
2743 i_1 = i_2+1
2744 end do
2745 end function eval_pot_ext

2775 !> Subtracts from the potential off the boundary the representation of
2776 !! the interior harmonic that equals it at the nearest boundary point.
2777 !!
2778 !! In the vacuum the representation of a potential that is harmonic inside
2779 !! the boundary is zero (eval_pot_ext()), so the subtraction changes
2780 !! nothing exactly. In the quadrature it removes the error that the double
2781 !! layer makes with the potential at the nearest boundary point, the part
2782 !! that grows without bound as the point approaches the boundary; what
2783 !! remains comes from the variation of the potential along the boundary and
2784 !! from the single layer. With \c psi_bnd the boundary values of the
2785 !! interior harmonic (the constant for the field-line style, \f$R^{|n|}\f$
2786 !! for the axisymmetric one) and \c pot_psi its representation, every
2787 !! column \f$c\f$ becomes \f$\phi(\vec{x},c) -
2788 !! \Phi_j^c/\psi_j\,\phi_\psi(\vec{x})\f$, \f$j\f$ the boundary point
2789 !! nearest to \f$\vec{x}\f$. For points in the vacuum only: inside the
2790 !! plasma the result is the potential of the nearest boundary point
2791 !! instead of zero.
2792 !!
2793 !! For the field-line style, with the gradient \c grad of the columns at
2794 !! the boundary points (grad_bnd_1()) and the representations \c pot_x of
2795 !! the coordinates x, y and z, the subtracted harmonic is the linear
2796 !! function \f$\Phi_j + \vec{g}_j\cdot(\vec{x}-\vec{x}_j)\f$, which
2797 !! matches the potential to first order at the nearest boundary point and
2798 !! removes the error of the potential's variation along the boundary as
2799 !! well. The constant alone leaves that error where the nearest boundary
2800 !! point lies on a neighbouring field line, a large part of a wavelength
2801 !! away in a mode of high toroidal mode number.
2802 subroutine sub_nearest(vac,x_ext,Phi_glob,psi_bnd,pot_psi,pot,grad,pot_x)
2803 ! input / output
2804 type(vac_type), intent(in) :: vac !< vacuum variables
2805 real(dp), intent(in) :: x_ext(:,:) !< points
2806 real(dp), intent(in) :: phi_glob(:,:) !< boundary values of the columns, n_bnd by n_c
2807 real(dp), intent(in) :: psi_bnd(:) !< boundary values of the interior harmonic
2808 real(dp), intent(in) :: pot_psi(:) !< its representation at the points
2809 real(dp), intent(inout) :: pot(:,:) !< representation of the columns at the points, n_ext by n_c
2810 real(dp), intent(in), optional :: grad(:,:,:) !< gradient of the columns at the boundary points, n_bnd by 3 by n_c (field-line style)
2811 real(dp), intent(in), optional :: pot_x(:,:) !< representation of x, y and z at the points, n_ext by 3
2812
2813 ! local variables
2814 integer :: id, kd ! counters
2815 integer :: j_min ! nearest boundary point
2816
2817 do id = 1,size(x_ext,1)
2818 j_min = minloc(sum((vac%x_vec-spread(x_ext(id,:),1,vac%n_bnd))**2,&
2819 &2),1)
2820 pot(id,:) = pot(id,:) - phi_glob(j_min,:)/psi_bnd(j_min)*pot_psi(id)
2821 if (present(grad) .and. present(pot_x)) then
2822 do kd = 1,3
2823 pot(id,:) = pot(id,:) - grad(j_min,kd,:)*&
2824 &(pot_x(id,kd)-vac%x_vec(j_min,kd)*pot_psi(id))
2825 end do
2826 end if
2827 end do
2828 end subroutine sub_nearest

3025 !> \public Plots the vacuum potential of computed eigenmodes outside the
3026 !! plasma.
3027 !!
3028 !! For every eigenmode of \c X_ids the normal data of the vacuum
3029 !! potential on the boundary are those of calc_vac_res(): along the stored
3030 !! normal \f$-\mathcal{J}\nabla\psi\f$, out of the vacuum, \f$\text{d}\phi =
3031 !! -\mathcal{J}\vec{B}\cdot\nabla X = -i(nq-m)X\f$, summed over the modes of
3032 !! the solution at the plasma edge with the basis \f$e^{i(n\alpha +
3033 !! (nq-m)\theta)} = e^{i(n\zeta_\text{F} - m\theta)}\f$ of the field-line
3034 !! style, or \f$e^{-im\theta}\f$ for the axisymmetric style, which splits
3035 !! off \f$e^{in\zeta_\text{F}}\f$. These data are \f$-\mathcal{J}Q_n\f$, with
3036 !! \f$Q_n\f$ the normal component of the magnetic perturbation that POST
3037 !! plots: the normal component of the perturbed field is continuous across
3038 !! the boundary. The boundary potential follows from the exterior system of
3039 !! solve_Phi_BEM(), the potential in the vacuum from Green's representation
3040 !! (eval_pot_ext()): for the field-line style the complex potential at the
3041 !! 3-D points, for the axisymmetric style \f$\hat{\phi}(R,Z)\f$ times
3042 !! \f$e^{in\zeta_\text{F}}\f$.
3043 !!
3044 !! The points lie in the planes of constant \f$\zeta_\text{F}\f$ of the
3045 !! plasma plots, \c n_zeta_plot values from \c min_zeta_plot to \c
3046 !! max_zeta_plot in units of \f$\pi\f$ (the geometrical angle is
3047 !! \f$-\zeta_\text{F}\f$ for VMEC and HELENA), on a grid of \c n_vac_plot
3048 !! points in \f$R\f$ and \f$Z\f$ from \c min_Rvac_plot to \c max_Rvac_plot
3049 !! and from \c min_Zvac_plot to \c max_Zvac_plot, in metres. Where a maximum
3050 !! does not exceed its minimum (the default), the range is that of the
3051 !! boundary points widened on both sides by half the larger of their widths
3052 !! in \f$R\f$ and \f$Z\f$.
3053 !!
3054 !! Written for every eigenmode: the real and imaginary parts of the
3055 !! potential at time zero, <tt>[id]_vac_pot_RE</tt> and
3056 !! <tt>[id]_vac_pot_IM</tt> (HDF5), and the boundary points with their
3057 !! normal data and potential, <tt>Data/[id]_vac_bnd.dat</tt>. Written once:
3058 !! <tt>vac_in_plasma</tt>, 1 inside the plasma and 0 in the vacuum (for the
3059 !! field-line style the side of the normal of the nearest boundary point
3060 !! close to it and minus the representation of the constant farther out,
3061 !! for the axisymmetric style the boundary polygon); the potential is set
3062 !! to zero there. Near the boundary the quadrature does not resolve the
3063 !! kernels; sub_nearest() removes the largest part of that error
3064 !! (check_vac_exact() prints the error against the distance, with and
3065 !! without it).
3066 !!
3067 !! \return ierr

3445 !> \public Calculates potential \c Phi on boundary of BEM in terms of some
3446 !! right-hand side .
3447 !!
3448 !! This is done by solving the system of equations
3449 !! \f$\overline{\text{H}}\overline{\Phi} =
3450 !! \overline{\text{G}}\overline{\text{R}}\f$,
3451 !! where \f$\overline{\text{R}}\f$ is the right-hand side, for example equal
3452 !! to \f$\overline{\text{E}}\overline{\text{P}}\f$ to solve in function of
3453 !! the individual Fourier modes.
3454 !!
3455 !! Both vacuum styles assemble \f$\overline{\text{H}}\f$ in the vacuum-side
3456 !! convention: the kernels take the normal derivative along the stored
3457 !! normal \f$-\mathcal{J}\nabla\psi\f$, out of the vacuum, and the diagonal
3458 !! carries \f$-2\beta\f$ with \f$\beta\f$ the vacuum's internal angle (the
3459 !! row-sum identity for the field-line style). Potentials that are harmonic
3460 !! in the vacuum and decay at infinity then satisfy
3461 !! \f$\overline{\text{H}}\overline{\phi} =
3462 !! \overline{\text{G}}\overline{\text{D}\phi}\f$, and potentials that are
3463 !! harmonic inside the boundary satisfy
3464 !! \f$\overline{\text{H}}\overline{\phi} - \overline{\text{G}}\overline{\text{D}\phi}
3465 !! = -4\pi\overline{\phi}\f$ (both verified in the full-stack tests). The
3466 !! corner term also makes the system nonsingular when the first and
3467 !! last points of a closed boundary coincide, as they do for HELENA: the two
3468 !! rows differ only in the column of that term.
3469 !!
3470 !! The linear system is solved with STRUMPack when PB3D was configured
3471 !! with it, and with ScaLAPACK LU (\c pdgesv) otherwise.
3472 integer function solve_phi_bem(vac,R,Phi,n_RPhi,n_loc_RPhi,lims_c_RPhi,&
3473 &desc_RPhi) result(ierr)

3476 use num_vars, only: check_vac, rank, n_procs

3483 real(dp), intent(in) :: r(:,:) !< \f$\overline{\text{R}}\f$
3484 integer, intent(in) :: n_rphi(2) !< \c n for \f$\overline{\text{R}}\f$ and \f$\overline{\Phi}\f$
3485 integer, intent(in) :: n_loc_rphi(2) !< local \c n for \f$\overline{\text{R}}\f$ and \f$\overline{\Phi}\f$
3486 integer, intent(in) :: lims_c_rphi(:,:) !< local limits for row and columns of \f$\overline{\text{R}}\f$ and \f$\overline{\Phi}\f$
3487 integer, intent(in), target :: desc_rphi(blacsctxtsize) !< descriptor for \f$\overline{\text{R}}\f$ and \f$\overline{\Phi}\f$
3488
3489 ! local variables
3490 integer, target :: desc_gr(blacsctxtsize) ! descriptor for GR
3491 integer :: info_loc ! info variable for ScaLAPACK
3492 integer, allocatable :: ipiv(:) ! pivot variable for the LU
3493 integer :: iwork_q(1) ! integer workspace query
3494 integer, allocatable :: iwork(:) ! integer workspace of the condition estimate
3495 real(dp) :: anorm, rcond ! 1-norm of the operator and its reciprocal condition number
3496 real(dp) :: work_q(1) ! workspace query
3497 real(dp), allocatable :: work(:) ! workspace of the condition estimate
3498 real(dp), external :: pdlange ! ScaLAPACK matrix norm
3499 logical :: solved_ok ! whether a verified solution was obtained
3500 real(dp), allocatable, target :: gr(:,:) ! GR
3501 real(dp), allocatable, target :: h_ext(:,:) ! copy of H, overwritten by the factorization
3502 character(len=max_str_ln) :: err_msg ! error message
3503#ifdef PB3D_WITH_STRUMPACK
3504 real(dp) :: sdp_err ! error
3505 real(dp) :: norms_loc(2) ! squared norms of residual and right-hand side
3506 real(dp), allocatable :: res_check(:,:) ! residual of the compressed solve
3507 real(dp), allocatable, target :: h_sdp(:,:) ! copy of H_ext for the compressed solver
3508 type(c_ptr) :: cdesch, ch ! C pointers to descriptor of H_sdp and H_sdp itself
3509 type(c_ptr) :: cdescgr, cgr ! C pointers to descriptor of GR and GR itself
3510 type(c_ptr) :: cdescphi, cphi ! C pointers to descriptor of Phi and Phi itself
3511 type(strumpackdensepackage_f90_double) :: sdp_loc ! Strumpack object for local solve H_sdp Phi = GR
3512#endif
3513#if ldebug
3514 integer :: lims_rl(2) ! vac%lims_r in local coordinates
3515 integer :: cd ! global counter for row and col
3516 integer :: cdl ! local counter for col
3517 integer :: i_rd, i_cd ! index of subrow and subcol
3518 character(len=max_str_ln) :: plot_title ! plot title
3519 character(len=max_str_ln) :: plot_name ! plot name
3520 real(dp), allocatable :: ang(:) ! angle
3521#endif

3523 ! initialize ierr
3524 ierr = 0
3525
3526 ! Only for processes that are in the blacs context
3527 if (in_context(vac%ctxt_HG)) then
3528 ! allocate auxililary matrices
3529 allocate(gr(vac%n_loc(1),n_loc_rphi(2)))
3530
3531 ! initialize descriptors
3532 call descinit(desc_gr,vac%n_bnd,n_rphi(2),vac%bs,vac%bs,0,0,&
3533 &vac%ctxt_HG,max(1,vac%n_loc(1)),ierr)
3534 chckerr('descinit failed for GR')

3536 ! calculate GR
3537 call pdgemm('N','N',vac%n_bnd,n_rphi(2),vac%n_bnd,1._dp,vac%G,1,1,&
3538 &vac%desc_G,r,1,1,desc_rphi,0._dp,gr,1,1,desc_gr)
3539
3540 ! copy the operator: the factorization overwrites it, and the
3541 ! original stays available for the residual check below
3542 allocate(h_ext(size(vac%H,1),size(vac%H,2)))
3543 h_ext = vac%H
3544
3545 solved_ok = .false.
3546
3547#ifdef PB3D_WITH_STRUMPACK
3548 ! try the compressed (HSS) solver first, on a copy of the
3549 ! operator so that the original stays available for the residual
3550 ! check and the possible fallback below
3551 allocate(h_sdp(size(h_ext,1),size(h_ext,2)))
3552 h_sdp = h_ext
3553
3554 ! set C pointers
3555 ch = c_loc(h_sdp)
3556 cdesch = c_loc(vac%desc_H)

3558 cdescgr = c_loc(desc_gr)
3559 cphi = c_loc(phi)

3564 sdp_loc%use_HSS=1
3565 sdp_loc%levels_HSS=4
3566 sdp_loc%min_rand_HSS=10
3567 sdp_loc%lim_rand_HSS=5
3568 sdp_loc%inc_rand_HSS=10
3569 sdp_loc%max_rand_HSS=100
3570 sdp_loc%tol_HSS=1d-12
3571 sdp_loc%steps_IR=10
3572 sdp_loc%tol_IR=1d-10
3573
3574 ! compression
3575 call sdp_f90_double_compress_a(sdp_loc,ch,cdesch)
3576
3577#if ldebug
3578 ! accuracy checking
3579 sdp_err = sdp_f90_double_check_compression(sdp_loc,ch,cdesch)
3580#endif
3581
3582 ! factorization
3583 call sdp_f90_double_factor(sdp_loc,ch,cdesch)
3584
3585 ! solve H Phi = G R
3586 call sdp_f90_double_solve(sdp_loc,cphi,cdescphi,cgr,cdescgr)
3587
3588#if ldebug
3589 ! accuracy checking

3591 &cdescphi,cgr,cdescgr)
3592#endif

3594 ! iterative refinement
3595 sdp_err = sdp_f90_double_refine(sdp_loc,ch,cdesch,cphi,cdescphi,&
3596 &cgr,cdescgr)
3597 deallocate(h_sdp)
3598
3599 ! Verify the solution: the randomized HSS compression can fail
3600 ! silently when the boundary operator has higher off-diagonal
3601 ! ranks than the hard-coded sampling parameters can capture
3602 ! (observed for the field-line 3-D style at moderate sizes). The
3603 ! residual is checked against the uncompressed operator, and on
3604 ! failure the solve falls back to ScaLAPACK LU below.

3606 res_check = gr
3607 call pdgemm('N','N',vac%n_bnd,n_rphi(2),vac%n_bnd,1._dp,h_ext,1,1,&
3608 &vac%desc_H,phi,1,1,desc_rphi,-1._dp,res_check,1,1,desc_gr)
3609 norms_loc(1) = sum(res_check**2)
3610 norms_loc(2) = sum(gr**2)
3611 call dgsum2d(vac%ctxt_HG,'all',' ',2,1,norms_loc,2,-1,-1)
3612 deallocate(res_check)
3613 if (norms_loc(1).le.1.e-12_dp*norms_loc(2)) then ! relative residual <= 1e-6
3614 solved_ok = .true.
3615 else
3616 call writo('The STRUMPACK solution has a relative residual '//&
3617 &trim(r2strt(sqrt(norms_loc(1)/max(norms_loc(2),&
3618 &tiny(1._dp)))))//' - falling back to ScaLAPACK LU',&
3619 &warning=.true.)
3620 end if
3621#endif
3622
3623 if (.not.solved_ok) then
3624 ! solve H Phi = G R with ScaLAPACK LU (pdgetrf and
3625 ! pdgetrs, what pdgesv does): the right-hand side is
3626 ! overwritten with the solution and the matrix destroyed
3627 ! (which is why H_ext is a copy). With check_vac the
3628 ! reciprocal condition number in the 1-norm is estimated

3630 phi(1:vac%n_loc(1),1:n_loc_rphi(2)) = gr ! same distribution
3631 allocate(ipiv(vac%n_loc(1)+vac%bs))
3632 ipiv = 0
3633 if (check_vac) then
3634 allocate(work(vac%n_loc(2)+vac%bs))
3635 anorm = pdlange('1',vac%n_bnd,vac%n_bnd,h_ext,1,1,&
3636 &vac%desc_H,work)
3637 deallocate(work)
3638 end if

3640 &info_loc)
3641 if (info_loc.ne.0) then
3642 ierr = 1
3643 err_msg = 'pdgetrf failed with info '//trim(i2str(info_loc))
3644 chckerr(err_msg)
3645 end if
3646 if (check_vac) then
3647 call pdgecon('1',vac%n_bnd,h_ext,1,1,vac%desc_H,anorm,&
3648 &rcond,work_q,-1,iwork_q,-1,info_loc)
3649 allocate(work(int(work_q(1))),iwork(iwork_q(1)))
3650 call pdgecon('1',vac%n_bnd,h_ext,1,1,vac%desc_H,anorm,&
3651 &rcond,work,size(work),iwork,size(iwork),info_loc)
3652 deallocate(work,iwork)
3653 call writo('CHECKVAC condition n_bnd='//&
3654 &trim(i2str(vac%n_bnd))//' norm1='//trim(r2strt(anorm))//&
3655 &' cond1='//trim(r2strt(1._dp/max(rcond,tiny(1._dp)))),&
3656 &persistent=rank.eq.n_procs-1)
3657 end if
3658 call pdgetrs('N',vac%n_bnd,n_rphi(2),h_ext,1,1,vac%desc_H,ipiv,&
3659 &phi,1,1,desc_rphi,info_loc)
3660 if (info_loc.ne.0) then
3661 ierr = 1
3662 err_msg = 'pdgetrs failed with info '//trim(i2str(info_loc))
3663 chckerr(err_msg)
3664 end if
3665 deallocate(ipiv)
3666 end if
3667
3668#if ldebug
3669#ifdef PB3D_WITH_STRUMPACK
3670 ! statistics
3671 call sdp_f90_double_print_statistics(sdp_loc)
3672#endif
3673
3674 ! user output
3675 ! set global angle (the same for every subrow and column; the
3676 ! subrow slices below use global indices, so ang has to span
3677 ! the whole boundary, also when the rows are distributed over
3678 ! multiple block-cyclic subrows)
3679 allocate(ang(vac%n_bnd))
3680 ang = reshape(vac%ang,[vac%n_bnd])
3681
3682 subcols2: do i_cd = 1,size(lims_c_rphi,2)
3683 col: do cd = lims_c_rphi(1,i_cd),lims_c_rphi(2,i_cd)
3684 ! set local column index
3685 cdl = loc_idx(lims_c_rphi,i_cd,cd)
3686
3687 subrows2: do i_rd = 1,size(vac%lims_r,2)
3688 ! set local row limits
3689 lims_rl = [loc_idx(vac%lims_r,i_rd,vac%lims_r(1,i_rd)), &
3690 &loc_idx(vac%lims_r,i_rd,vac%lims_r(2,i_rd))]
3691
3692 ! output
3693 plot_title = 'for column '//trim(i2str(cd))//&
3694 &' and starting row '//&
3695 &trim(i2str(vac%lims_r(1,i_rd)))
3696 plot_name = '_'//trim(i2str(cd))//'_'//&
3697 &trim(i2str(vac%lims_r(1,i_rd)))
3698 call print_ex_2d('Phi '//trim(plot_title),&
3699 &'Phi'//trim(plot_name),&
3700 &phi(lims_rl(1):lims_rl(2),cdl),&

3706 end do col

3710 deallocate(ang)
3711#endif
3712
