This page contains the technical documentation of the PB3D project. A pdf version can be downloaded here.

PB3D calculates the linear ideal MHD stability at high toroidal mode number \(n\) of 3-D equilibria from VMEC and of axisymmetric equilibria from HELENA. The plasma edge can be a fixed boundary (BC_style(2) = 1) or a free boundary (BC_style(2) = 2, the default). For a free boundary, PB3D calculates the vacuum response with a boundary-element method: a 3-D method along the magnetic field lines for VMEC, and an axisymmetric method for HELENA (see Vacuum response). The post-processing program POST plots, among other things, the vacuum potential outside the plasma (see Code outputs).
