\doxysubsection{Detailed Description}
The flattened variable type used for internal HDF5 storage. 

It has its own module, without HDF5, so that modules whose only HDF5 connection is this type, such as PB3\+D\+\_\+utilities, can be compiled and unit-\/tested without the HDF5 library.
