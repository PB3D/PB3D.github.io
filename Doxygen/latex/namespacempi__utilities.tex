\doxysubsection{Detailed Description}
Numerical utilities related to MPI. 

This includes a lock system, which can be both BL (blocking) or NB (non-\/blocking). It is based on the implementation of an MPI-\/\+IO atomic mode without file support, described in \DoxyCite{rossatomicio}{number}{1}.

\begin{DoxySeeAlso}{See also}
See \doxylink{namespacempi__vars}{mpi\+\_\+vars}.
\end{DoxySeeAlso}
The reason for this was the fact that using a simple lock file can lead to crashes.

\begin{DoxyNote}{Note}
A downside of this method is that in some rare cases a deadlock may occur as the master process, which contains the shared variable with a window that other processes may use, is idle and waiting, whereas the others are still performing lock options. As the master is idle and waiting, its MPI asynchronous communication is not performed. To remedy this, just call wait\+\_\+\+MPI() after procedures where lock operations are performed. 
\end{DoxyNote}

{\footnotesize\ttfamily \label{namespacempi__utilities_ad1ecd33327d11c2dc7c5e96eb11f970c} 
integer function, public mpi\+\_\+utilities::\+calc\+\_\+mem\+\_\+procs (\begin{DoxyParamCaption}\item[{real(dp), intent(inout)}]{mem\+\_\+procs}{, }\item[{real(dp), intent(inout)}]{mem\+\_\+meas}{}\end{DoxyParamCaption})}



Memory that all processes together hold before the work starts \+[MB]. 

Every process takes the largest resident size it has had so far from getrusage(), and the processes add their values. Called after the equilibrium has been read and before the equilibrium jobs start, this is the memory of the program itself, MPI, the libraries and the input, which calc\+\_\+memory\+\_\+eq(), calc\+\_\+memory\+\_\+x() and calc\+\_\+memory\+\_\+sol() do not contain. It is private to every process: a PB3D process holds about 200 MB without input and 275 to 330 MB after reading an equilibrium (Snellius, foss/\+2025a), of which shared library pages are about 5 \%.

The result is this sum times the same 50\% safety factor as in calc\+\_\+memory\+\_\+eq(), calc\+\_\+memory\+\_\+x() and calc\+\_\+memory\+\_\+sol(). The factor also covers the memory that PETSc, SLEPc and MPI take later in the run: on Snellius a process grows from about 300 MB at the start to about 380 MB in a W7-\/X run on four processes. {\ttfamily mem\+\_\+meas} returns the sum itself.

\begin{DoxyNote}{Note}
{\ttfamily ru\+\_\+maxrss} is given in kB on Linux and in bytes on mac\+OS.
\end{DoxyNote}
